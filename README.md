# gma-sdk-native-icon-example

Google Mobile Ads SDK と FluctSDK GMA アダプターを利用してネイティブ広告（main / icon 画像）を表示するサンプルアプリです。

ネイティブ広告の画像は以下のロジックで表示します。

1. main 画像があれば main 画像を表示する
2. main 画像がなければ icon 画像を表示する
3. どちらもなければ画像は表示しない

## ディレクトリ構造

```
/ios      ... iOS サンプルアプリ
/android  ... Android サンプルアプリ
```

各プラットフォームの詳細はそれぞれのディレクトリの README を参照してください。
